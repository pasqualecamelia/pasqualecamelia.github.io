The claim, in one line

From pure constants — the golden ratio φ, √5, π and fixed integers — with no measured value of α used anywhere, the theory returns a single inverse fine-structure constant:

α⁻¹ = (20φ⁴ − 13·ε₇) / (1 − 2φ×10⁻⁷)
    = 137.0359991703
with ε₇ = √5·π/7 − 1 = 0.003544961577…,  20φ⁴ = 70 + 30√5

This sits −0.32σ from CODATA 2022 (137.035999177(21)). The comparison to data enters only here, after the value is built; the value itself is a parameter-free forward cascade. Every identity above is re-derived from the formulas, not hard-coded, by a deterministic audit that passes 36/36.

Honest caveat: which species was assigned to which weight was chosen using the same 2018/2020 numbers, so the agreement of the two known points is partly built in. Genuinely blind and untested are (i) the discreteness for any new species and (ii) the direction the two known values move as they sharpen. This is a dated conditional forecast, not yet a derived one.

What would kill it

If improved recoil values converge on a single common number instead of sorting onto discrete steps; or if any new species lands off the set at 3σ; or if the rubidium value drifts away from 137.035999215 at 3σ — the prediction is dead. It is meant to be wrong if it is wrong.
